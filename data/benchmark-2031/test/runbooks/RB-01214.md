# Export not picked up

## When to use

Use this runbook when payroll-partner-sftp doesn't pick up the export.

## Procedure

1. List the files waiting.
2. Compare their names with the agreed pattern.
3. Send the file again with the right name.

## Warnings

- Agree name changes with the partner first.
