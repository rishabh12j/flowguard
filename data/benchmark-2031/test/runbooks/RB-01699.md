# A partition is stuck

## When to use

Use this runbook when a partition stops making progress.

## Procedure

1. Find the offset that keeps failing.
2. Move that message to the dead-letter queue.
3. Check the partition catches up.

## Warnings

- Don't skip more than the bad message.
