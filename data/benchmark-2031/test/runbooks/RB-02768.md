# TLS errors calling ledger-partner-api

## When to use

Use this runbook for TLS handshake failures with ledger-partner-api.

## Procedure

1. Read the handshake error.
2. Check the provider's certificate dates.
3. Contact the provider.

## Warnings

- Never turn off certificate checks.
