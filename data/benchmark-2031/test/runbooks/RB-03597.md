# Callbacks from ledger-partner-api fail signature checks

## When to use

Use this runbook when ledger-worker rejects ledger-partner-api callbacks as unsigned or wrongly signed.

## Procedure

1. Compare the callback's key ID with the cached keys.
2. Fetch the provider's published keys.
3. Process the rejected callbacks again.

## Warnings

- Never accept callbacks without a valid signature.
