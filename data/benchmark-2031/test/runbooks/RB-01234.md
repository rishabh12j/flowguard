# Token requests to returns-partner-api fail

## When to use

Use this runbook when returns-worker can't get an access token from returns-partner-api.

## Procedure

1. Read the token endpoint's error code.
2. Compare the token request with the provider's documentation.
3. Roll back a recent change to the token request.

## Warnings

- Never log the client secret.
