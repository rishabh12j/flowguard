# Updates for unknown orders

## When to use

Use this runbook when rewards-worker rejects updates for orders it doesn't have.

## Procedure

1. Check when the order was created.
2. Check how messages are ordered.
3. Replay the updates.

## Warnings

- Keep each order's messages in order.
