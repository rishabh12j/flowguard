# Calls to billing-partner-api time out

## When to use

Use this runbook when calls to billing-partner-api time out.

## Procedure

1. Check the provider's status page.
2. Hold retries while the provider is degraded.
3. Resend failed calls after recovery.

## Warnings

- Don't raise the timeout without limit.
