# bookings-partner-api rejects tokens

## When to use

Use this runbook when bookings-partner-api answers 401 to bookings-worker.

## Procedure

1. Read the error's reason.
2. Check the token's audience and expiry.
3. Roll back a recent change to token requests.

## Warnings

- Never log tokens.
