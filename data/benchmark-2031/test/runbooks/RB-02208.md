# procurement-partner-api rejects tokens

## When to use

Use this runbook when procurement-partner-api answers 401 to procurement-worker.

## Procedure

1. Read the error's reason.
2. Check the token's audience and expiry.
3. Roll back a recent change to token requests.

## Warnings

- Never log tokens.
