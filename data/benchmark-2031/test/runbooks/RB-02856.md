# inventory-worker restarts

## When to use

Use this runbook when inventory-worker restarts again and again.

## Procedure

1. Read why the container was stopped.
2. Compare its memory use with the limit.
3. Restore a limit that fits.

## Warnings

- Don't remove limits.
