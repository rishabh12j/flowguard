# bookings-partner-api quota used up

## When to use

Use this runbook when bookings-partner-api says a key's quota is used up.

## Procedure

1. Check who else uses the key.
2. Give each consumer its own key.
3. Resend the refused calls.

## Warnings

- Never share keys between services.
