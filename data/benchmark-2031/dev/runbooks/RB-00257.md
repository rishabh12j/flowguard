# Writes to loyalty-db refused

## When to use

Use this runbook when loyalty-processor gets permission errors from loyalty-db.

## Procedure

1. Check which role loyalty-processor connects with.
2. Check that role's grants.
3. Restore the missing grant or roll back the change that removed it.

## Warnings

- Grant only what the service needs.
