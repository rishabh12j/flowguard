# Messages processed twice

## When to use

Use this runbook when loyalty-worker processes a message twice.

## Procedure

1. Compare processing time with the visibility timeout.
2. Restore a timeout longer than the processing time.
3. Undo the duplicates.

## Warnings

- Don't delete messages by hand.
