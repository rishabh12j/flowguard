# Writes to inventory-db refused

## When to use

Use this runbook when inventory-processor gets permission errors from inventory-db.

## Procedure

1. Check which role inventory-processor connects with.
2. Check that role's grants.
3. Restore the missing grant or roll back the change that removed it.

## Warnings

- Grant only what the service needs.
