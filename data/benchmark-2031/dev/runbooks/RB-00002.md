# Writes to rewards-db refused

## When to use

Use this runbook when rewards-processor gets permission errors from rewards-db.

## Procedure

1. Check which role rewards-processor connects with.
2. Check that role's grants.
3. Restore the missing grant or roll back the change that removed it.

## Warnings

- Grant only what the service needs.
